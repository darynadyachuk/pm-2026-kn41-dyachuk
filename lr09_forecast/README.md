## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | Власний скрипт Python (`simulate.py`) |
| Прогонів | 10000 |
| Що тягнеться випадково | Значення velocity одного зі своїх закритих спринтів (18 або 12 SP з масиву `[18, 12]`) |
| Дата, від якої відлічуються спринти прогнозу | Для сценарію «Весь перший реліз» — кінець Спринта 1 (2026-10-25); для сценарію залишку — кінець Спринта 2 (2026-11-08) |

```
import math
import random

velocity = [18, 12]
simulations = 10000
remaining_points = 28

results = []
for _ in range(simulations):
    rem = remaining_points
    sprints = 0
    while rem > 0:
        v = random.choice(velocity)
        rem -= v
        sprints += 1
    results.append(sprints)

results.sort()

# Обчислення P50 та P85 за індексами
p50_sprints = results[int(0.50 * simulations)]
p85_sprints = results[int(0.85 * simulations)]

print(f"P50: {p50_sprints} sprints, P85: {p85_sprints} sprints")
```
